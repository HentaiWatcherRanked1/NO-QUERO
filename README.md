# Convoy Web v3

New layout inspired by modern driving-stat / multiplayer apps.

## Added
- Drives screen with recent runs
- Stats screen with top speed + speed distribution
- Crew tab
- Map tab
- Road-safety reporting for:
  - crash
  - stopped vehicle
  - debris
  - construction
  - closure
  - emergency activity
  - other hazard
- 5-second temporary alert followed by a persistent pink marker for the rest of the day (prototype behavior)
- Existing editable map, draggable crew/spots, route editing, GPS, and marker-mode toggle remain

## Note
This prototype does not include police-tracking or law-enforcement evasion features.
Real road-event data still needs a traffic/event data source or community reports.
